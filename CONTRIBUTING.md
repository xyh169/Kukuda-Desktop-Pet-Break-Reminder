# Contributing to Kukuda

Thanks for helping Kukuda grow.

## Good first contributions

- Improve or review the te reo Māori wording.
- Add playful, restorative dialogue.
- Refine Kiwi animation and drawing.
- Improve accessibility and multi-display behaviour.

## Development

Kukuda requires macOS 13 or later and Apple's Command Line Tools.

```sh
./测试.command
KIWI_BREAK_NO_OPEN=1 ./构建并运行.command
```

Before opening a pull request, run the tests and confirm the application launches.
Please keep new dialogue kind, concise, and suitable for a general audience.
